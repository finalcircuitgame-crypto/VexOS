# VexOS built-in fonts

VexOS uses **real upstream font families**, not a newly invented typeface or
custom-drawn glyphs:

1. **Inter** — default UI font. SIL Open Font License 1.1.
   https://github.com/rsms/inter/blob/master/LICENSE.txt
2. **Lato** — alternative sans-serif. SIL Open Font License 1.1.
   https://github.com/googlefonts/lato/blob/main/OFL.txt
3. **DejaVu Sans** — alternative sans-serif and fallback. Bitstream Vera /
   DejaVu font license.
   https://github.com/dejavu-fonts/dejavu-fonts/blob/master/LICENSE
4. **DejaVu Sans Mono** — monospace face for terminal-style text. Bitstream Vera
   / DejaVu font license.
   https://github.com/dejavu-fonts/dejavu-fonts/blob/master/LICENSE

The build rasterizes the original regular and bold font faces into a compact
framebuffer atlas. The glyph outlines are not redesigned; only rasterization,
antialiasing, and the existing compact cell metrics are adapted for VexOS.
Coverage is stored at 4 bits per pixel (16 alpha levels), and bold uses the
font's actual bold face instead of artificially thickening regular glyphs.

The atlas is generated by `tools/prepare_font_atlas.py`. Install Python Pillow
and the matching font packages before building. The kernel embeds the atlas;
it does not load TTF/OTF files at runtime or depend on a runtime font engine.
The original CGA bitmap font remains available as a fallback for bytes outside
the built-in ASCII atlas.


## Generating the atlas on Windows

Install Pillow once:

```powershell
py -m pip install Pillow
```

Download the static **regular and bold** font files for all four families listed
above, and place them anywhere underneath `assets/fonts/`. The generator
searches this folder recursively, so keeping each family in its own subfolder
is fine. Keep the upstream license files with the font downloads.

Then run:

```powershell
py tools\prepare_font_atlas.py --output assets\fonts\
```

The directory form of `--output` writes `assets/fonts/font_atlas.bin`.
Alternatively, use `--font-dir "C:\path\to\fonts"` to point at another
folder. The generator also checks the normal Windows, macOS, and Linux font
locations automatically.
