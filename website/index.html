01 / THE PROJECT

Not a theme.
A whole system.

VexOS is a hands-on systems project: a custom kernel, low-level hardware work, persistent storage, and a desktop environment that runs on top of it. The goal is to understand the machine by building the software that brings it to life.

↳From firmware handoff
to a usable desktop.

02 / UNDER THE HOOD

Small pieces.
One working system.

A look at the core subsystems currently taking shape inside VexOS.

01BOOT

EFI boot pipeline

A UEFI boot path loads the kernel and passes the boot information it needs to start up.

UEFI→BOOT INFO→KERNEL
02MEMORY

Memory management

Physical and virtual memory management, plus a kernel heap.

PMMVMMHEAP
03HARDWARE
PCI↔USB

Hardware support

PCI enumeration and xHCI USB controller support as the hardware layer grows.

PCIXHCIINPUT
04STORAGE

Persistent storage

A SimpleFS storage image gives the system a place to keep files between boots.
