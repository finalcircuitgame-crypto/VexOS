# VexOS

VexOS is a small educational x86_64 operating system project that boots via an EFI bootloader and runs a minimal kernel with a simple desktop environment. It includes basic kernel subsystems (PMM, VMM, heap, tasking), PCI/xHCI support, a SimpleFS persistent storage image, and a fullscreen setup wizard.

## Key features
- EFI bootloader (src/boot) that loads kernel.elf and passes a BootInfo struct
- Kernel core (src/kernel/core): framebuffer console, PMM (physical memory manager), VMM (virtual memory), heap, PCI enumeration and drivers (xhci), simple desktop UI and setup wizard
- SimpleFS persistent storage image (dist/storage.img) and image embedding helper in run.sh

## Prerequisites
- GNU toolchain: gcc, ld, objcopy, make
- mtools (mformat, mmd, mcopy) for writing the EFI image
- qemu-system-x86_64 and OVMF (UEFI firmware) for running the VM
- python3 (optional) used by run.sh to embed new.png into dist/storage.img

## Build
Run:

    make

By default the doomgeneric usermode components are skipped to avoid requiring Allegro. To enable them:

    make BUILD_DOOMGENERIC=1

## Run (development)
run.sh builds then launches QEMU with OVMF. It will also embed `new.png` into the SimpleFS storage image if that file exists.

    ./run.sh

## Notes & warnings
- Large binary artifacts (dist/tiny64.img, dist/storage.img) exceed GitHub recommended sizes; consider using git-lfs or excluding build artifacts from the repository.
- There is an embedded/added path at `src/doom` that may be a nested repo/submodule. If accidental, remove from the index with `git rm --cached src/doom` and add `.gitignore` entries.

## Desktop performance and UI

The desktop caches its background and restores a 26 by 26 pixel region when
moving the cursor. Scene changes still redraw the desktop. The frame limiter
halts between timer interrupts and polls USB on each wake. Rendering and
allocator objects use compiler optimization with general-purpose registers;
hardware drivers retain their original optimization level.

The launcher and window controls share their painted and clickable bounds.
The floating silver taskbar has labeled app buttons, new icons, hover feedback,
and a compact layout for smaller displays. Focused windows have a teal divider, and the
workspace card displays detected memory and framebuffer dimensions.

To run the headless UI smoke test from Linux or WSL:

    make dist/kernel.elf dist/BOOTX64.EFI
    python3 tools/ui_smoke.py

The test boots copies of both disks, completes setup, opens the launcher and
terminal, moves the pointer, types into Notepad, and checks the saved file in
the copied storage image. Screenshots and serial output are saved under
`build/ui-review`. It requires QEMU, mtools, Python 3, and OVMF at
`/usr/share/OVMF`. It currently exercises the default 1280 by 800 display.
